# Contributing

Follow the [quick start](quick-start.md) and
[development guide](development/local.md). Make focused changes in the relevant
backend or frontend repository, preserve authorization and transaction boundaries,
and verify changed behavior with appropriate tests or builds.

Keep documentation aligned with the implementation. Add current guides to navigation,
use synthetic examples and generic hosts, and mark proposed behavior explicitly.
See [documentation maintenance](development/documentation.md).

The backend repository's `CONTRIBUTING.md`, `SECURITY.md`, and `CODE_OF_CONDUCT.md`
contain the contribution and reporting policies. Report vulnerabilities privately
to this HeadsUp repository's maintainers; do not use the upstream template's tracker.
